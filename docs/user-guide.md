# User guide

## Connect a wallet

Install Freighter, select Stellar Testnet, and connect from the application header. Keep enough testnet XLM for transaction fees and use only test assets.

## Create a market

Open **Create**, enter an objective question and resolution description, choose a resolver address, select the settlement token, and set the close and timeout values. Review the transaction before approving it in Freighter.

## Stake

Open a market, select YES or NO, enter an amount, review the summary, and approve the wallet transaction. One wallet may stake on both sides.

## Claim or refund

After resolution, open the market and claim. YES/NO winners receive their proportional share of the total pool. Invalid markets refund deposits. On-chain reads remain authoritative if the indexer is temporarily delayed.
